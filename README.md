## 🇬🇧 English

If you've ever played a Magus or any character loaded with abilities, you know the struggle: the panel keeps expanding upward until it pierces the screen. This mod gives you complete control over the interface.

### ✨ Key Features

* **Drag-to-Resize:** Click and drag the edges or upper corners to freely adjust the panel's width and height.
* **Mouse Wheel Scrolling:** Adds vertical scrolling with a clean mask, so your abilities never block the view again.
* **Smart Layout:** The panel stays anchored to the bottom while resizing, with an option to center icons horizontally.
* **UMM Integration:** Easily customize max size limits, scroll sensitivity, border thickness, or save/reset your layout directly in Unity Mod Manager.
* **Multilingual:** Supports English and Russian out of the box.

### 🛠️ Installation

1. Install the latest version of **Unity Mod Manager (UMM)** for *Pathfinder: Wrath of the Righteous*.
2. Download the mod archive from [Nexus Mods](https://www.nexusmods.com/pathfinderwrathoftherighteous/mods/1169?tab=description) or GitHub Releases.
3. Drag & drop the `AbilityPanelResize.zip` file into the Unity Mod Manager **Mods** tab (or extract it into `<GameFolder>/Mods/AbilityPanelResize`).
4. Enjoy!

## 🇷🇺 Русский

Если вы когда-нибудь играли за Магуса или любого персонажа с кучей способностей, то прекрасно знаете эту проблему: панель бесконечно разрастается вверх, пока не пробьёт экран. Этот мод даёт контроль над интерфейсом.

### ✨ Основные возможности

* **Ресайз мышью:** Позволяет свободно менять ширину и высоту панели, просто потянув за края или верхние углы.
* **Прокрутка колесиком:** Внедряет удобную вертикальную прокрутку, скрывая лишние иконки во внутреннем контейнере.
* **Удобная компоновка:** Нижняя грань панели остается зафиксированной, а иконки можно автоматически центрировать.
* **Гибкие настройки:** В меню Unity Mod Manager можно изменить чувствительность скролла, толщину зоны захвата, лимиты размера и включить запоминание габаритов между сессиями.
* **Поддержка языков:** Полный перевод интерфейса на русский и английский языки.

### 🛠️ Установка

1. Установите **Unity Mod Manager (UMM)** для *Pathfinder: Wrath of the Righteous*.
2. Скачайте архив с модом с [Nexus Mods](https://www.nexusmods.com/pathfinderwrathoftherighteous/mods/1169?tab=description) или из раздела Releases на GitHub.
3. Перетащите `AbilityPanelResize.zip` архив во вкладку **Mods** в окне UMM, либо распакуйте содержимое в каталог игры: `<Папка с игрой>/Mods/AbilityPanelResize`.
4. Растягивай эту суку!
